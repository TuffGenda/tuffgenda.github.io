2042

Feburary 2nd-Feburary 27th, 2026

This project was another team project where we were tasked to make a recreation of an arcade game from scratch using Vulkan and Gateware in C++. I did not do the 3D graphics programs but what I did do was manage the team of students, create the powerups, created the audio, and compressed the project to allow shipping. This project taught me how to be a team leader, how to ship games, and how easy and difficult making a game from scratch could be. It was easy in the sense that it did not take much to ship the game but it was difficult to make this game, even in a team, with only a month. However, the difficulty taught me how to overcome obstacles and to work together to make a great game.
